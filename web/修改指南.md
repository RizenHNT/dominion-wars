# 网页界面修改指南（P3）

界面与引擎已彻底解耦：本目录（web/）是纯前端文件，引擎规则全部在 Java 服务端。
**改外观不会影响任何游戏规则**，改坏了恢复文件即可。

## 你最常改的三个地方

| 想调什么 | 改哪里 |
|---|---|
| 颜色、卡牌大小、动画时长、横幅停留、默认语言、是否自动弹教程 | `web/config.js`（每项都有中文注释） |
| AI 出招速度（逐步播放的节奏） | `data/ui.json` 的 `aiStepMs`（毫秒） |
| 教程文案与步骤 | 在 `config.js` 末尾定义 `window.DW_TUTORIAL = { zh:[{sel:"#hand",text:"..."}], ... }` 即可整体覆盖 |

改完保存 → 浏览器刷新即生效（不用重启游戏）。

小技巧：地址栏加 `#pve` 或 `#watch` 可跳过大厅直接开局（如 http://127.0.0.1:8137/#pve）。

## 图片皮肤（UI 素材替换）

所有界面元素都留了图片插槽：把素材放进 `web/skin/`，在 `config.js` 的 cssVars 里填
`"--img-xxx": "url('skin/xxx.png')"` 即可。插槽未设置时使用内置绘制样式，
因此可以一张一张逐步替换，完整插槽清单与推荐尺寸见 `web/skin/说明.txt`。

## 进阶

- **换皮**：`style.css` 顶部 `:root` 里是全部设计变量；更深度的布局改 `index.html`。
- **卡图**：把 PNG 命名为 `卡牌ID.png` 放进 `data/art/`，或直接用卡牌编辑器的「选择卡图…」按钮。
- **协议**（想自己写新界面/做联机）：
  - `GET /api/decks` 卡组列表
  - `POST /api/new` `{deckA,deckB,mode:"pve"|"watch"}`
  - `GET /api/state` 完整对局快照（含 pending 待决策、events 动画事件、logs）
  - `POST /api/cmd` `{type:"play"|"ambush"|"attack"|"endAmbush"|"endTurn"|"answer", uid, target, face, id, choice}`
  - 引擎是唯一规则权威：所有指令都会被服务端校验，非法操作返回 `{ok:false,msg}`。
