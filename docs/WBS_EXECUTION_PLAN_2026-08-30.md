# Dominion Wars — WBS 执行计划（按周额度周期）

> 版本：2026-08-23
>
> 目的：把现有 WBS 转成可持续执行的周周期计划。每个周期从额度重置日开始，直到该周期的额度用尽前完成本周期的收尾，不把“计划”当成“已完成”。
>
> 权威边界：`docs/RULES.md`、`docs/DESIGN.md`、`design/runtime-kit-v1.31/contracts/`、`docs/PROGRESS_WBS.md`、PL/QA 报告。规则、平衡、最终视觉和发布仍由人类/PL拥有最终决定权。

## 1. 状态定义和完成定义

| 状态 | 含义 |
|---|---|
| `DONE` | 实现、相关测试、报告证据都齐全；没有只靠静态文件冒充运行时通过 |
| `READY` | 依赖满足，Codex/Lunar 可以直接领取 |
| `QA_PENDING` | 实现已完成，等待独立 DeepSeek QA 或人工 Unity 验收 |
| `HUMAN_REQUIRED` | 需要人类确认规则、平衡、视觉、素材版权或发布决策；不得猜 |
| `ENVIRONMENT_BLOCKED` | 代码可继续，但 Unity/Hub/许可证/连接桥等外部环境未满足 |
| `DEFERRED` | 明确留到后续扩展包或后续版本，不算当前版本缺陷 |

一个交付只有同时满足“代码/资源落地 + 相关测试 + 报告交接”才算完成。Unity 需要额外区分：

- 编辑器自动编译成功 ≠ EditMode/PlayMode 通过。
- EditMode/PlayMode 通过 ≠ Windows Player 干净机通过。
- 8 月 21 日的 Unity 24/24、2/2 和 Windows 旧证据不自动覆盖 8 月 23 日的新改动。

## 9. 每周额度周期计划

每周不是“工作一周后停止”，而是一个完整执行批次；下一次额度重置后继续领取未完成项。

### 周期 1：2026-08-30 起 — 技术可玩 MVP

目标：完成 U-00～U-03 的最小闭环，能用占位素材打一局基础对战。

- 关闭/回归 R-01（10.11.8）。
- 复验当前 Adapter/Unity 编译门禁。
- 完成牌桌中立布局、五阶段显示、合法行动按钮和快照刷新。
- 完成出牌、攻击、结束回合、PULL 的点击路径。
- 每个批次都做 `.NET + Unity EditMode`；不能操作 Unity 时标 `ENVIRONMENT_BLOCKED`，不宣称通过。

### 周期 2：下一次重置 — 事件和恢复闭环

目标：从“能点动作”提升到“能完整解释一局发生了什么”。

- 完成 U-04 惩罚链和事件时间线。
- 完成 U-05 的最小动作反馈与 Reduced Motion 开关。
- 完成 U-06 结果页、重开、数据加载失败和错误 session 恢复。
- 关闭 E-08 五条核心路径端到端测试。

### 周期 3：再下一次重置 — 内容接入

目标：从技术样机进入内容完整可试玩版。

- 完成 A-03/A-04 导入和统领 fallback。
- 处理已经拍板的 R-02～R-05；未拍板项保持隔离，不猜数值。
- 完成 C-01 Deck Builder 和 C-02 卡牌详情的非最终视觉版本。
- 接入已确认的卡牌/牌组/本地化资源。

### 周期 4：再下一次重置 — QA 和发布候选

目标：形成可交给 PL/QA 的 Release Candidate。

- Q-01～Q-06 全量回归。
- Q-07 功能矩阵闭环。
- Q-08 分辨率、输入、Reduced Motion、可读性。
- Q-09 性能与长局。
- Q-10 干净机 Windows 包和回滚记录。

### 周期 5 及以后：缓冲和美术完成

- A-05 91 张正式卡图、版权和最终视觉。
- A-06 skin、最终主题、音效和动效精修。
- 新增规则/补充包单独开周期，不插入已锁定的发布候选。

## 10. 额度使用纪律

每个周周期固定分配：

1. 前 60%：实现一个完整、可运行的纵切。
2. 中间 20%：独立 QA、边界测试、PL 复核。
3. 最后 20%：修复、回归、报告、交接和可撤回状态确认。

不允许用最后额度继续开新功能；不允许在未验证的 Unity 层写“通过”；不允许把“找到了问题”当作交付完成。

模型分工建议：

- Sol：每周期只用于一次高层范围/冲突决策和最终汇总。
- Lunar Max：实现代理、测试代理、低风险修复和报告。
- PL/DeepSeek：规则、数值、验收和阻塞分类。
- 人类/GPT Web/美术：最终视觉、91 张卡图、版权、发布确认。
