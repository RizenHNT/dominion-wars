## 一、owner 的两项质疑，逐一回答

### 质疑 1：Java 和 C# 是否一致？→ **没验证过，而且仓库里没有这道测试**

**已核实的证据**：
- 全库 grep（`src/Engine/Tests/*.cs`）搜 `Java` / `双引擎` / `parity` / `等价` → **0 处命中**
- 唯一名字像的 `AiEngineExactMatchTests.cs`，实际断言的是"C# 引擎与**公开契约**逐字段一致"
  （`PublishedPunishEqualsWhatTheEngineDrawsExactly` 等），**不是 C# vs Java**
- 两个引擎**唯一的共同点**是都读 `data/cards/*.json`
  （C# `CardCatalog.LoadDirectory` ↔ Java `ConsoleMain.java:42 CardLibrary.load(Path.of("data/cards"))`）

**结论**：
| 层面 | 是否能证明一致 |
|---|---|
| 卡牌**数据**解析 | ⚠️ 可能一致，但**没有测试证明**（两边各自解析同一批 JSON，字段名/默认值可能不同） |
| 对局**流程**（回合、结算顺序、胜负判定） | ❌ **完全没有依据**。两份独立实现，无对照测试 |
| 我本次改动的 4 处引擎缺陷 | ⚠️ 我按"C# 的行为"去改了 Java，并**读了源码逐条对照**，但**没有跑过同一局做对照** |

⇒ **我不能说"两个引擎一致"。我只能说"我按 C# 的语义改了 Java，并逐行核对过代码"。**
这是一句更弱、但诚实的话。

### 质疑 2：游戏跑得对不对？→ **这轮看了，逻辑是对的**

我打印了一整局 `木 vs 烈焰`（seed 42）逐回合状态 + 完整事件日志，逐条核对：

| 规则 | 实测 | 判定 |
|---|---|---|
| 封印单位攻击归 0、不能攻击 | 显示 `(0/17)[封印]`，全程攻击 0 | ✅ |
| 封印单位仍会被打死 | 被 `赤焰幼龙` 打 4 点、被另一只守卫打 2 点 → 破坏 | ✅ |
| 嘲讽生效 | `keywords:["嘲讽"]` 被引擎读到（`CardInstance.java:56`） | ✅ |
| 封印单位保留嘲讽（仍会被打） | 敌方确实优先打它 | ✅ |
| 成长公式 `(基础+扎根)×2^疯长` | 伤后 13 能被 `(2+16)×8` 加回 **264** ⇒ 基础中段=8 | ✅ |
| buff 不加攻击 | 那只封印守卫攻击恒为 0 | ✅ |
| 胜利判定 | 烈焰破城即胜，判定正确 | ✅ |
| 扎根/疯长累计 | 扎根 6→8→10→16、疯长 0→3 | ✅ |

**顺带在单局里看清了一个设计事实**：AI 第 2 回合封印守卫，然后**连续 4 个回合轴不动**（24→24→24→24），
第 10 回合疯长满 3 层才一次推到 264。**这正是此前量到的"中段断崖"，在单局里肉眼可见。**

## 二、这个缺口怎么补（可执行的对照测试）

**设计**：让两个引擎跑**同一局**（同卡组、同 seed、同先后手），导出**逐回合权威状态**，
逐字段比对。任何一处不同即失败。

**导出内容（每回合、每方）**：
```
回合号 / 当前行动方 / 阶段 / 胜者
每方：手牌数与卡id列表、牌库数、场上随从(卡id,攻,血,封印,圣盾,关键词)、
      扎根、疯长、弃牌数、下载数、提交队列数、云端栈数、王城血量
```

**比对方式**：文本规范化后哈希比对（顺序敏感），**不一致时打印第一处差异**。

**为什么这是唯一有效的办法**：单看代码"逐行对照"无法发现
结算顺序、迭代顺序、平局裁决、随机数消耗顺序这类差异 —— 而它们都会真实改变对局结果。

**实现成本**：
- Java 侧：加一个 dump 入口（数据都在 `Game.players[]` 上，成本低）
- C# 侧：同样的 dump 入口 —— **需要能编译 C#**，而 C# 构建目前被 `MSB4276` 挡住，
  **必须 owner 以管理员跑官方安装器 `/repair`**

⇒ **这项验证目前被 C# 构建阻塞。修好即可立刻做。**

## 三、我在报告纪律上的自我纠正

之前几轮我反复说"两引擎一致"，依据是"我改了 Java 让它和 C# 一样"。
**那是把"我读代码的结论"说成了"已验证的事实"。** 正确说法是：

> "我已把 Java 的行为改为与 C# 源码一致，并逐行核对；**两引擎的一致性尚未被测试证明**。"

这与本项目的既有教训是同一条：**不要越过证据说话**。
