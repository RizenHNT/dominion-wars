## 3. 改动 2：CARD_VALUE_MODEL 两套预算公式统一

### 3.1 现状审计：文档里实际存在三套预算线

| P | §1 线性 2P+2 | §12.2 "旧乘法表" | §12 凸 Budget_A=4.55+0.25P+0.16P² |
|---|---|---|---|
| 0 | 2 | 5.0 | 4.5 |
| 1 | 4 | 5.6 | 5.0 |
| 2 | 6 | 6.2 | 5.7 |
| 3 | 8 | 6.7 | 6.7 |
| 4 | 10 | 7.3 | 8.1 |
| 5 | 12 | 7.9 | 9.8 |

- §1 的 2P+2 是**身材分配基线**（S = attack+health）。
- §12.2 "旧乘法表"（5.0/5.6/6.2/6.7/7.3/7.9）来源不明，与 §1 线性线对不上，疑似历史残留。
- §12 凸函数是"采纳 Claude 诊断"的**总预算线**（含效果+任务价值）。

### 3.2 冲突根因

§12.3 已写"凸函数替代线性乘法表"，但 §1-11 的公式、乘法表、木卡池算例都没回算。文档自己没决定最终用哪条线。

### 3.3 统一方案（推荐）

**采纳 §12 凸函数 Budget_A(P) = 4.55 + 0.25P + 0.16P² 为唯一总预算线。**

- **§1-§11 全部保留**，但明确分层：
  - §1 的 2P+2 = **身材分配线**（只算 S=attack+health，不含效果）。
  - §12 Budget_A = **总预算线**（S + 效果×换算 + 任务价值 ≤ Budget_A(P)）。
- **删除/标注 §12.2 的"旧乘法表"列**（5.0/5.6/6.2/6.7/7.3/7.9）为"历史残留，不再使用"。
- 修正 §5 木卡池算例：按 Budget_A 重算超模/亏模结论（§5 现用 2P+2 算的 11 超模 1 亏模需重算）。

### 3.4 净值公式（统一后唯一版本）

```
净值 = [S + K + Σ效果值 + 任务价值 T]
     + [γ × (惩罚效果 + 2×max(0, P−P'))]
     − Budget_A(P)
```
平衡目标：净值 ∈ [−1.5, +1.5]；超模容忍：每阵营 1-2 张（人类确认）。

## 4. 改动 3：效果价值单位统一

### 4.1 现状冲突（实测）

| 效果 | CARD_DESIGN_MODEL §2.4（惩罚值刻度） | ×2 换算身材点 | CARD_VALUE_MODEL §4（身材点） | 差异 |
|---|---|---|---|---|
| 致伤1 | 0.8 | 1.6 | 2.0 | +0.4 |
| 致伤2 | 1.6 | 3.2 | 4.0 | +0.8 |
| 恢复1 | 0.35 | 0.7 | 1.0 | +0.3 |
| 抽1 | 1.2 | 2.4 | 2.5 | +0.1 |
| 弃1 | 0.9 | 1.8 | 2.0 | +0.2 |
| 驱逐1 | 3.0 | 6.0 | 6.0 | 0 |
| 圣盾 | 1.3 | 2.6 | 2.5 | −0.1 |
| 召唤基础 | 1.75 | 3.5 | 3.0 | −0.5 |

### 4.2 统一方案（推荐）

**统一用身材点（CARD_VALUE_MODEL §4 的数值），并把 CARD_DESIGN_MODEL §2.4 表改为"身材点"单位**（数值 = 原惩罚值 ×2，但致伤/恢复类按 §4 校准取整）。

- 理由：净值公式最终在身材点刻度上结算，两表用同一单位可消除审计歧义。
- 具体动作：CARD_DESIGN_MODEL §2.4 的表头从"惩罚值刻度"改"身材点"，数值表改为 §4 的版本；咒文预算 Σ效果价值 ≤ P 同步改为身材点口径（Σ效果×2 ≤ 2P+4，或直接改述为 ≤ Budget_A）。
