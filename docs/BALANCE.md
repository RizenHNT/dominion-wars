# 《统御战纪》平衡说明

## 1. 最新模拟数据（AI 对 AI，每对阵 8 局 × 12 对阵 = 96 局）

| 卡组 | 胜率 |
|---|---|
| 烈焰帝国 | 56.3% |
| 机械遗迹 | 52.1% |
| 古木圣地 | 50.0% |
| 深海联盟 | 41.7% |

- 平均对局长度：**15.4 个玩家回合**，节奏符合预期（10–20 回合区间）。
- 所有阵营胜率落在 40%–60% 的可接受带内；烈焰略强、深海略弱，留作首批真人测试的观察点。

复现命令：

```bash
java -Dfile.encoding=UTF-8 -Dstdout.encoding=UTF-8 -Dstderr.encoding=UTF-8 -cp build/classes:build/test-classes com.dominionwars.test.SimMain 8
```

（参数为每个对阵的局数，可加大以降低方差。）

## 2. 已做过的平衡调整记录

1. **深海胜利门槛 15 → 12**，同时裁定：弃牌阶段的强制弃牌**不计入**"对方累计弃牌"胜利计数（防止深海挂机自动赢），仅效果弃牌与惩罚转化弃牌计入。
2. **AI 惩罚预算**：限制 AI 每回合通过出牌喂给对方的总惩罚抽牌量（`4 + turn/4`，对方手牌≥7 时 −2，己方威压期 +2，单回合惩罚出牌 ≤3）。该改动使对局平均回合数从 ~11 提升到 ~15，避免互喂手牌导致的雪崩节奏。
3. **先驱威压**改为"对方卡牌惩罚值 +1"（并保留"己方惩罚值 −N"备选配置），激励抢先打出统领。

## 4. 建议的后续平衡流程

1. 真人对局收集烈焰 vs 深海的体感数据（重点：深海是否需要把门槛回调到 11，或给惩罚转化加保底）。
2. 用 `SimMain 30` 以上的样本量验证任何数值改动。
3. 数值改动只动 `balance.json` 与卡牌 JSON，引擎代码无需重编。

## 王城正式版平衡修正（2026-06-12，Claude）

基线：Castle Prototype v7（机械 70.8% / 古木 60.4% / 烈焰 39.6% / 深海 29.2%）。

三项修正：
1. **古木**：王城受到敌方造成的伤害时，打断对方的「无伤」计数（争夺王城即破无伤，按 v7 文档建议 6.2 实现）。
2. **机械**：上古极神 Alpha 特殊胜利阈值 8 → 9。
3. **深海**：新增「对方弃牌时」联动钩子（onOpponentDiscardEffects，场上触发、防套娃深度 4）：
   - 暗礁海妖：对方每因效果弃 1 张，+1/+1；
   - 深海狱卒：对方每因效果弃 1 张，对王城造成 1 点伤害（弃牌转化为攻城压力）；
   - 退潮 惩罚 2→1、幼年利维坦 惩罚 4→3。

修正后模拟（120 局，互打全矩阵）：

| 卡组 | 胜率 |
|---|---|
| 烈焰帝国·焚天速攻 | 45.0% |
| 机械遗迹·极神协议 | 50.0% |
| 深海联盟·吞噬之渊 | 56.7% |
| 古木圣地·常青壁垒 | 48.3% |

平均回合数 17.4，全部落入 45–57% 区间；规则测试 35/35 通过。
