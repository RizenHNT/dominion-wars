### 0.1 全局出牌博弈结构（核心设计原则 · 2026-08-15 人类定稿）

**本游戏的核心张力 = 出牌双刃剑**：

| 时点 | 卡牌效果模板 | 玩家心理 |
|---|---|---|
| **自己回合·主动打出** | **低收益模板**（致伤1/恢复1/+1/+1 级；身材正常/偏低） | **谨慎出牌**——主动效果弱 + 出牌喂对面惩罚抽牌 = 出牌不划算 |
| **对方回合·被惩罚抽到** | **正常模板**（致伤2-4/抽牌/破坏/群体级；被动触发） | **期待对方出牌**——对方出牌喂我 → 我抽到惩罚降临 → 反制对方 |

**设计推论**：
1. **所有卡主动效果 = 低收益**（v6 费用阶梯：0 极弱/1-2 正常/3-5 高收益；但整体压低——"抽卡不稀奇，效果不值钱"）。
2. **惩罚降临（punishActivatable）= 正常模板**——被动触发不滥用，是卡牌的核心价值层；**普通卡（非仅 PUNISH 牌）应普遍带惩罚降临**（≥40% 卡），被喂牌时发挥。
3. **出牌节奏博弈**：双方犹豫出牌（怕喂对面）、被迫出牌（任务/场面需要）、期待对方出牌（等喂牌反制）——这是对局节奏与心理博弈的来源。
4. **控制卡组（木）**：更倾向"少出牌、等对方喂、惩罚反制 + 任务推进"，主动效果弱 + 惩罚降临强。
5. **快攻卡组（烈焰）**：主动效果可略强（进攻需要出牌推进），但仍受"喂对面"约束——快攻用低惩罚卡（P0-1）降低资敌。

## 0. 设计原则（方法论声明）

1. **自顶向下**：每个阵营先定义"节奏档 + 胜利轴 + 资源模型"，再倒推卡牌；卡牌是模型的实例，不是独立创作。
2. **一切可量化**：身材、效果、费用（惩罚值）统一到同一价值单位；任何卡都能写出价值等式。
3. **弱点是对称设计**：阵营的强项（如烈焰进攻）必须对应弱点（法术资源交换亏）——由模型显式规定，不是事后找补。
4. **机制字段允许追加**：关键词/字段按需扩展（§5），Schema 扩展清单随设计冻结。
5. **验证闭环**：设计完成后做统计分布检验 + 模拟器实测（授权后），不满足模型的卡回炉。

## 1. 全局节奏模型

### 1.1 时间轴
- 目标对局：**15 ± 3 玩家回合**（BALANCE.md 实测带，作为节奏标尺）。
- 资源流：起手 5 + 每回合抽 1 ≈ 第 n 回合可用手牌 ≈ 5 + n；手牌上限 8 强制弃牌管理。

### 1.2 节奏档（Tempo Band）——阵营速度定位
| 阵营 | 档位 | 发力回合 | 胜利轴 | 节奏特征 |
|---|---|---|---|---|
| 烈焰 | 快攻 T1 | 5-8 | 随从交换抢血 → 击败随从统领 / 直伤斩杀 / 王城破城 | 每回合压伤害，低惩罚少喂牌 |
| 机械 | 中速 T2 | 8-12 | 上传下载转换 → alpha 6 次 下载 | 前期防守蓄力，中期转换爆发 |
| 深海 | 中速 T2 | 8-12 | 潮位标记兑现 + 弃牌 12 张 | 前期铺场叠标记，中期消费兑现 |
| 古木 | 控制 T3 | 10-15 | 无伤 6 回合 | 扛伤恢复拖后期，防守反击 |
| 中立 | 工具 — | 通用 | 无独立胜利轴 | 各阵营外挂 |

### 1.3 伤害输出模型（节奏检验）
- 快攻（烈焰）第 n 回合对统领的累计期望伤害 ≈ Σ(随从攻击 × 存活回合) + 直伤法术。
  - 要求：第 6-8 回合累计 ≥ 8-12（击败随从统领），或达成王城压力。
- 中速（机械/深海）第 8-12 回合开始持续输出；前期以防守/标记为主。
- 控制（古木）第 10-15 回合达成无伤胜利；期间需吸收对手全部伤害。

### 1.4 手牌/惩罚值经济
- 打出惩罚值 = 喂给对手的抽牌量。对手第 n 回合手牌增量 ≈ Σ你打出的惩罚值。
- **设计规则**：快攻卡组整副惩罚值总和低（≤110），控制卡组可高（≤140）——因为控制后期手牌不重要，喂牌风险小。
- 惩罚值上限 20、连锁 20 层（balance.json）——效果值换算上限据此冻结。

### 1.5 核心目标（Core Target）语义 —— 本游戏"打脸"的真实定义
- **不存在"玩家脸"**。直伤/攻击的最终目标 = **核心目标**（引擎 damageEnemyCore）：随从统领 / 耐久统领 / 赋予生命统领的玩家生命 / 共享王城。
- **核心未降临 → 直伤落空**（引擎 log"统领尚未降临，伤害落空"）；多核心并存（如王城 + 已降临统领）→ 由玩家/AI 选择分配。
- **设计推论**：
  1. ENEMY_FACE 价值低于"指定单体伤害"（ENEMY_TARGET 可打随从/随从统领/任何在场目标）——FACE 条件化。
  2. 速攻前期不能无脑打脸（核心可能未降临）；随从交换（清场+推统领）是主节奏。
  3. **冲锋（召唤当回合可攻击王城）价值极低**：王城 75 血 + 嘲讽限制 + 核心未降临风险 → 不引入"冲锋"关键词（避免照搬炉石）。
  4. 王城破城（DAMAGE_CASTLE）是独立慢轴（75 血累计），烈焰破城胜利 = 长期目标，不是速攻手段。

## 2. 随从身材公式（Vanilla Test 扩展）

### 2.1 基础身材（白板）
```
身材点数 S = attack + health = 2P + 2        （P = 惩罚值）
P:  0 → S 2  (1/1)    P: 1 → S 4  (2/2)
P: 2 → S 6  (3/3)    P: 3 → S 8  (4/4)
P: 4 → S 10 (5/5)    P: 5 → S 12 (6/6)
```
- **统一刻度：1 惩罚值 = 2 身材点（S = attack + health）**。这是"标准白板线"。
- 随从总价值（身材点）：S + Σ效果惩罚值×2 + Σ关键词修正 ≤ 2P + 2。
- 咒文总价值（惩罚值刻度）：Σ效果价值 ≤ P（超模卡/阵营强项允许 +20%）。
- **节奏修正**：快攻随从为换当回合打点（突袭/连击），允许身材亏 1-2 点，标注"节奏"不视为超模。

### 2.2 关键词修正（从 S 扣除）
| 关键词 | 修正 | 说明 |
|---|---|---|
| 嘲讽 TAUNT | −1 | 强制对方优先攻击 |
| 圣盾 DIVINE_SHIELD | −1 | 挡一次伤害 |
| 突袭 RUSH | −1 | 召唤当回合可攻击随从 |
| 扰魔 SPELL_WARD | −0.5 | 不能成为咒文目标 |
| 潜行 STEALTH（新） | −0.5 | 不能成为敌方单目标；首次攻击后显形 |
| ~~冲锋 CHARGE~~ | ~~−1.5~~ | **删除**：无玩家脸 + 王城 75 血 + 嘲讽限制，价值过低（2026-08-15 人类反馈） |
| 吸血 LIFESTEAL（新） | −0.8 | 造成伤害时恢复等量己方生命 |

### 2.3 攻击/生命分配（按节奏档）
```
快攻（烈焰）：攻 ≈ 0.6S，血 ≈ 0.4S     （压迫性分布，交换中赚节奏）
中速（机械/深海）：攻 ≈ 血 ≈ 0.5S      （均衡）
控制（古木）：攻 ≈ 0.3S，血 ≈ 0.7S      （生存性分布）
```

### 2.4 效果价值表（惩罚值刻度；随从带效果 = 从身材预算扣效果×2）
| 效果 | 价值（惩罚值） | 备注 |
|---|---|---|
| 1 点单体伤害 | 0.8 | DAMAGE@ENEMY_TARGET（主动效果；惩罚降临可同值） |
| 1 点核心伤害（ENEMY_FACE） | 0.55 | 打核心目标；核心未降临落空，多核心可选 |
| 1 点 AOE | 1.2 | DAMAGE@ALL_ENEMY_MINIONS |
| 抽 1 张 | 1.2 | DRAW |
| 对方抽 1 张 | 0.4 | OPP_DRAW（喂牌） |
| 随机弃 1 | 0.9 | DISCARD_OPP_RANDOM |
| 破坏 1 随从 | 3.0 | DESTROY |
| 治疗 1 点 | 0.35 | HEAL |
| +1/+1 单随从 | 0.8 | BUFF |
| 圣盾授予 | 1.3 | GRANT_KEYWORD |
| 突袭授予 | 1.0 | GRANT_KEYWORD |
| 潜行授予 | 0.5 | GRANT_KEYWORD |
| 召唤 1 基础随从 | 1.5-2.0 | SUMMON |
| 本回合对方惩罚+1 | 0.5 | ADD_OPP_PUNISH_TURN |
| 对王城 1 点伤害 | 0.6 | DAMAGE_CASTLE |
| 强制结束对方回合 | 4.0+ | END_TURN（仅统领级） |

**卡牌价值等式（统一刻度）**：
- 随从：S + Σ效果×2 + Σ关键词修正 ≤ 2P + 2
- 咒文：Σ效果价值 ≤ P（超模卡/强项 +20%）
- 超模 >10% 必须标注风险补偿；节奏件（§2.1）除外

## 3. 阵营资源模型（核心：胜利轴倒推）

### 3.1 烈焰帝国 —— 进攻 / 随从交换
- **节奏档**：T1 快攻。**胜利轴**：随从交换抢血 → 击败随从统领；直伤斩杀；王城破城（flame ROYAL_CASTLE_BREAK）。
- **随从占比**：60-65%（进攻是随从游戏）。
- **身材**：攻高血低（§2.3 快攻分布），关键词优先突袭（当回合打点）。
- **法术定位（弱点设计）**：单体解场、直伤允许高效；**过牌/AOE 贵**（非进攻型资源交换 = 弱点）——烈焰法术预算中，过牌类 ≥3 惩罚，AOE 效率低于中速阵营。
- **卡组惩罚值目标**：≤110（全场最低，少喂牌 = 进攻节奏不送资源）。
- **随从交换服务卡型**：白板好身材、突袭、连击（RESTORE_ATTACKS）、嘲讽（保护打点）、交换后收益（buff/亡语）。

### 3.2 机械遗迹 —— 0 费 / 上传下载双轴
- **节奏档**：T2 中速转换。**胜利轴**：上传下载转换 → alpha **6 次 下载**（§11.1 定稿）。
- **随从模型**：普通出牌**惩罚全 0**（RULES §12.4 基线），身材 = S(0)=2-3（1/1-2/2 级）。
- **费用分配模型**：每张机械卡价值 = 基础身材(2-3) + **上传收益**（提交/上传）+ **下载收益**（下载/回滚）。
  - 上传件（提供 COMMIT/PUSH）：价值预算 30-40% 在 上传/提交 效果。
  - 下载件（提供 PULL）：价值预算 30-40% 在 下载效果（且 下载 推进胜利计数）。
  - 转换卡（提交/下载 动作咒文）：价值 = 动作本身 + 触发效果。
- **弱点**：0 费身材低 → 前期场面弱 → 需墙/清场拖节奏；被弃牌流拆燃料（提交队列依赖手牌）。
- **卡组惩罚值目标**：≤100（0 费随从多，全场最低——对手几乎不被喂牌，转换收益是"净价值"）。

### 3.3 深海联盟 —— 潮位标记系统
- **节奏档**：T2 中速。**胜利轴**：潮位标记兑现（主）+ 弃牌 12 张（副，sea_leader 定稿）。
- **标记系统模型（潮位）**：
  - **来源卡**（叠标记）：身材 = 基准 − 潮位价值；潮位价值 1 潮位 = 1.0 价值。
  - **消费卡**（兑现）：身材 = 基准 + 潮位 × 兑现系数；兑现系数 1.2-1.5（兑现比叠加更赚，驱动成组）。
  - **循环**：来源(前期低费) → 累积 → 消费(中期) → 循环。来源:消费卡比例 ≈ 1.2:1。
  - **前期成组**：0-2 惩罚低费随从同步叠标记，2-3 惩罚消费卡兑现——前期有场面 + 标记双线。
- **弱点**：标记不兑现 = 亏（来源卡亏身材）；潮位可被对手消耗/清除（若设计反制）→ 兑现时点博弈。
- **卡组惩罚值目标**：115-125（中速基准）。

### 3.4 古木圣地 —— 大后期控制 / 养巨物（低面板随从 + 强法术工具）
- **节奏档**：T3 大后期控制（2026-08-15 人类方向修正：**大后期卡组形态 = 低面板随从（活着当载体/嘲讽）+ 强法术工具（解场/生存/过牌/回复）**，随从不做强面板——面板由 buff 引擎叠出）。
- **胜利轴**：把一只己方非统领随从养成巨物——**生命阈值目标 512（2^9 主题）**，达成即胜（评审⑪裁决：**乘法不进 MVP**，故为加法 buff 累积；扎根=加法强化累积，非乘法）。
- **任务组件（养巨物三件套，字段化：扎根/疯长）**：
  1. **成长载体**：高血随从（封印候选），生命池越厚越接近 512；
  2. **扎根（ROOT，普通 buff·加法计数器）**：玩家级计数器 rootStacks——打出一张含扎根的卡 → rootStacks += N；**施加强化时按计数器数量增加 buff 量**：强化量 = 基础 + rootStacks × 4（1 层 +4、2 层 +8，蓄力型；2026-08-15 平衡修正：增幅 4/层）；层数随强化应用消耗（"下一张卡牌"语义），玩家级进度不因目标离场重置（§12.2）；
  3. **疯长（RAMPANT，统领 buff·乘法计数器）**：玩家级计数器 rampantStacks（**特殊的扎根**）——统领/专属卡提供；**每施加一个 buff 就累乘一次**：强化量 ×= 2^rampantStacks（持续全局倍增）；**疯长层上限 3（×8）**，无伤续费到上限停止（2026-08-15 平衡修正：防指数爆炸）；512 = 2⁹ 主题：扎根加法垫底 → 疯长乘法翻倍冲刺；
  4. **封印**：**仅被扎根/疯长增幅的强化**才使目标进封印（无法攻击 + 失去所有特殊能力，E7）——普通 buff（无增幅）不封印，保留木的场面能力；
  5. **平衡基值（方案 B + v6 阶梯）**：growth P3（3 费高收益）+4/+4、扎根增幅 4/层、疯长上限 3 层（×8）→ 每张增幅强化增益 ≈(4+4)×8=64 → **512 需 8 张增幅 buff（15 回合紧张）；建议阈值 256-384 区间平衡测试**（512 作为扩展主题目标）。
6. **效果强度阶梯（v6，人类指导·核心）**：**本游戏抽卡不稀奇（惩罚机制喂牌→手牌泛滥）→ 普通卡效果必须弱**：致伤1/恢复1/+1/+1 是常态，惩罚值是正常模板（卡均带 P0-5）。**费用-收益阶梯**：P0=极弱（1/1-1/2 无效果，进构筑但无收益）；P1-2=正常（致伤1-2 级）；P3-5=高收益（致伤4/群体2/驱逐/操纵/+4/+4）。
7. **惩罚值策略**：木卡正常惩罚（P1-3 为主），惩罚机制双向运转；惩罚组件充足（4 惩罚牌 + 普通卡惩罚降临）。
8. **双层卡牌设计（v7-v8，人类定稿）**：每张卡两层效果——**主动打出**（低收益模板：0 费极弱/1-2 正常/3-5 高收益）+ **惩罚降临**（被惩罚抽到时触发，**正常模板强度**；被动不滥用）。
9. **惩罚降临普及（v8）**：**大部分卡（≥60%，木 86%）带惩罚降临**（普通卡非仅惩罚牌），**响应费用低费为主（cost 0-1）**——低响应费让惩罚降临易发动，形成"对方出牌→我反制"博弈。
10. **打印惩罚值压低（v8，防无限连锁）**：**打印惩罚值 1-2 为主，3-5 偏少**（仅高收益/终结件，如 treant P5）——打印值高→喂对面多→连锁激烈→无限连锁风险；低打印值控制连锁烈度（配合 balance.json chainLimit=20）。**与主动出牌费用相反：出牌费用可 1-2 偏多，但惩罚降临费用反而低费偏多**。
- **防御模型**（保护成长载体）：嘲讽墙 ≥6 张、治疗 ≥ 对手场均伤害、圣盾保护关键随从。
- **弱点**：前期场面弱、解场贵（AOE 稀缺）、被速攻压制；**巨物可被破坏/驱逐/硬解**（对手反制出口：DESTROY 硬解成长载体 = 进度清零，养巨物需重新开始）；王城破城是独立威胁。
- **v3 设计方向（2026-08-15 人类指导）**：①增加伏击/嘲讽/圣盾/治疗/debuff，减少直接随从交换，转向**破坏 / 洗回卡组（E13）/ 短暂操纵（E14）**；②防御不过度强化（嘲讽 4、圣盾 1 源、治疗 2 源为限）；③**手牌抉择**：防守卡（debuff/反制/治疗）与任务卡（buff/过牌/扎根源）竞争 8 张手牌位——每回合决策"守还是进"；④**普通卡也带惩罚降临**（非仅 PUNISH 牌：owl 抽1、druid 群体治疗）。
- **卡组惩罚值目标**：130-140（控制后期喂牌风险小）。
- **胜利轨道修正**：古木不依赖"无伤胜利"（NO_DAMAGE_TURNS_GE 为旧枚举，人类纠正：重做方向=养巨物）；**无伤降级为"疯长续费条件"**（非胜利条件）。
- **wood_leader 疯长供给（三段）**：
  1. **正常出场**（enterEffects）：提供少量疯长（rampantStacks +1）；
  2. **惩罚出场**（punishEffects，被惩罚抽到="乘法出场"）：提供更多疯长（rampantStacks +2，RULES §7 惩罚出场强化）；
  3. **在场持续**：每回合结束时若己方本回合未受任何伤害 → rampantStacks +1（继续提供疯长；受伤中断增长，已积累层保留）。
- **反制出口**：对手打伤害（随从/直伤/王城）中断疯长增长；硬解成长载体（DESTROY）清零养巨物进度需重养。

### 3.5 中立 —— 工具包
- 无独立胜利轴；数值 = 各阵营基准的中位数；通用件（过牌/直伤/嘲讽/治疗/解场）。
- 每阵营卡组可外挂 8-12 张中立。

### 5.2.1 扎根/疯长处理规则（引擎结算规格，E6）
```
施加强化（BUFF 类效果，amount = base）时：
1. 扎根增幅：amount += rootStacks × 4        // 按计数器数量加 buff（蓄力型，方案 B：4/层）
   随后 rootStacks = 0                        // 消耗（"下一张卡牌"语义）
2. 疯长增幅：amount ×= 2^rampantStacks       // 每有一个 buff 累乘一次（持续，不消耗）
3. 封印判定：仅当本次强化受扎根/疯长增幅（rootStacks>0 或 rampantStacks>0）→ 目标进封印 sealed
4. 若目标死亡/离场：已消耗层数不返还；未消耗层数保留（玩家级）
```
- 扎根来源：木 buff 卡（生命绽放、常青林冠、扎根之根、幼苗护卫等，≥5 张）
- 疯长来源：wood_leader 降临（+1 层，惩罚出场 +2）；**疯长层上限 3（×8）**，无伤续费到上限停止
- 平衡基值（方案 B）：base=4、扎根 4/层、疯长上限 3 → 6 张 buff 达成 512
- 计数器对双方可见（公开成长状态，§12.2）

## 6. 设计流程分解（每阵营 5 步）

1. **定义**：节奏档 + 胜利轴 + 资源模型（本文件 §3 已定）。
2. **随从模板**：按 §2 公式生成各费段白板基准（0-5 惩罚各 1-2 张）。
3. **协同件**：服务胜利轴的效果随从（占随从 40%），效果价值从身材预算扣除。
4. **法术/伏击/惩罚**：按阵营弱点与曲线规范填充。
5. **统计检验**：价值分布曲线、阵营均值差、协同-反制矩阵、卡组曲线（§7 执行）。

## 7. 统计验证协议（每阵营完成后执行）

- V1 价值分布：Σ(卡价值 − 预算) 应落在 [−2, +2] × 卡数 ±10%；无单卡超模 >10% 未说明。
- V2 曲线检验：低/中/高费占比符合 §4.1。
- V3 阵营均值差：四阵营平均身材点数差 ≤ ±1.5（避免整体强度带漂移）。
- V4 协同-反制矩阵：每阵营 ≥3 条协同链，每条 ≥1 个明确反制出口。
- V5 模拟器实测（Java）：将设计转**临时数据文件**（`data/cards/*.v1.json` 或独立目录，**不覆盖生产 JSON**），跑 `java -cp "build/classes;build/test-classes" com.dominionwars.test.SimMain 8` 出 4×4 胜率矩阵；胜率带 40-60%、对局时长 12-18 回合为通过；**跑完清理临时文件还原 data/**。
- V6 回归守护：临时数据测试前后 `dotnet test` 与 Java 38/38 保持全绿（证明测试过程无污染）。

### 13.5 风险定价（Claude 框架，600 样本校准）
