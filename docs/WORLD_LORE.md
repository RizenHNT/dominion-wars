# 《统御战纪》世界观基准 / WORLD LORE

> 状态：Canonical worldbuilding baseline（2026-09-15）
>
> 核心原则：**先有世界与历史，后有卡牌。** 卡牌效果、惩罚值、抽弃牌、特殊胜利、登场条件等均为玩法抽象，不得反向决定历史事实。

## 1. 玩家可见的世界

人类生活在巨大的钢铁大陆架上。这里没有天然意义上的岩石大陆：大地由无法复制的巨型钢板、机械壳体、框架、管道、贯穿结构、空洞与层层叠压的古代构件组成。大陆彼此分离，并存在上下高差；它们会长期缓慢漂移，短周期内大量位移会回摆，只有跨越许多周期才形成可观测净漂移。大陆碰撞极端罕见。

世界拥有明确重力与上下方向，但人类不知道最下方是什么。钢铁大陆之外、下方与巨型孔洞深处通常表现为黑暗；已知世界没有传统意义上的全球海洋，但大陆上存在水体、冰、水循环与完整生态。

天空长期明亮。蓝色网状现象遍布空间，既像云、蛛网、流光，也呈现可利用的资源活动。人类可以穿过它，并通过经验性的“采猎”获得可储存、转让的蓝色资源，却无法把蓝色现象本身作为普通样本捕获。蓝能可以驱动加热、冷却、照明、食物生产、医疗、方向力与飞行等技术。

这个文明很早就掌握了飞行，却无法复制脚下大陆级的古代巨构。

### 九色

人类天然把可见颜色分成九类。对他们而言这和呼吸一样普通。其生理与物理底层原因尚未被文明彻底解释。

### 休息与归属

人需要进食，也需要“休息”。休息过程中会逐渐产生自然的“充盈”感，达到完成状态后自行结束，不依赖昼夜。历史上，一个人的社会归属曾与长期休息地点密切绑定。

### 无战争文明

本世界**没有战争**。这不等于没有争斗：欺骗、仇恨、政治竞争、制度博弈、经济施压、处罚与大型共同体冲突都存在。文明长期偏好通过公开、可见证的仪式处理争端，并在数千年中发展出越来越复杂的制度。

“攻击、弑君、破城、随从”等游戏术语属于《统御战纪》的表现语言，不等于历史世界存在军队战争。

## 2. 地理骨架

已知世界包含约 2–3 个大陆架级巨型钢铁区域，以及许多中小型碎片。

- **第一大陆架**：存在高达数公里的巨型钢铁山系，实际是古代机械结构形成的巨大垂直障碍。
- **第二大陆架**：中央长期存在极强蓝色资源光，远望如蓝色河流或银河汇聚。这里后来成为世界最重要的遗迹谜团之一。
- **第三大陆架**：整体较平坦，仅有少量大型断崖，是理解普通城市、聚落与日常社会的基准区域。

方向称呼（如早期“东西大陆”）属于某一历史时期的相对地理语言，不代表大陆永久固定。

## 3. 四个主要卡组来源名称

下列名称是世界内真实历史名；“烈焰 / 深海 / 古木 / 机械”只作为玩家识别用的玩法标签。

- **赫萨廷**〔烈焰〕：后期历史中的大型政治共同体。与高热蓝能、强执行力和统领传统存在深厚联系，但不是靠战争征服形成的“火焰帝国”。
- **纳维恩诸邑**〔深海〕：由多种深层聚落、下层水域与贯穿结构周边共同体长期演化出的复合政治网络。“诸邑”保留其多中心传统。
- **依兰维索**〔古木〕：隐藏在巨大钢铁结构内部的罕见生态世界。它的历史并不以人类政治为中心，人类长期甚至不知道它存在。
- **克莱恩书院**〔机械〕：后世研究、保存并尝试理解古代巨构与遗留造物的重要学术—技术传统。它与世界历1187年建立的“学院”有知识谱系关系，但并不简单等同于最初的学院。
- **无阵营 / 中立**：跨共同体人物、早期历史人物、旅行者、思想家、无法归入后世势力者，以及“命运”相关历史切片。

## 4. 统领

“统领”不是普通行政官职。

统领是足以代表大型文明共同体最高政治人格、仪式权威与对外意志的历史级存在。一个共同体可能几代乃至更久都不会出现真正被后世承认为统领的人。统领的出现、继承与公开确认本身即可成为纪年事件。

世界历1842年出现“储君”式制度：重要职位的未来继承者第一次在现任仍在位时获得制度性确认。世界历2595年，首次出现具有巨大公共象征意义的“统领加冕”。世界历2602年随即出现未经完整加冕却实际履行统领职责者，引发新的合法性争论。

## 5. 历史主轴（世界历）

“世界历”目前是作者与游戏资料使用的统一时间坐标，不保证世界内所有地区自古使用同一纪年。

### 早期与第一次共同历史

- **286**：依兰维索对应的隐秘古木生态已经存在于钢铁巨构内部；人类未知。
- **304**：一棵巨木倒塌并改变内部地下水系。无人类记录。
- **438**：两个巨型大陆架上的人类首次稳定接触。资源猎人塞安·洛维尔、导航员弥拉·赫登与另一侧的涅娅·索恩等人在蓝色资源带上相遇。最初因仪式差异互相误解，最终通过共享可理解的蓝能操作建立交流。之后的跨大陆纠纷催生“双见证程序”的早期雏形。
- **562**：第三大陆架一处大型水盆因旧贯穿孔重新打开而排水，形成干湖带。
- **633–639**：第一大陆架经历六年蓝色资源贫期，远距运输第一次从便利条件变成重要基础设施。
- **702**：《多即是少》语录体文本形成。它回应了跨大陆交流之后知识、规则与资源同时膨胀的问题。
- **741**：仅约三分之一内容的删节抄本因便携、易记而传播得比完整版本更广，反过来塑造后世对原典的理解。
- **784**：一种薄软生物沿潮湿焊缝大规模扩散，成为钢铁世界常见生态成员。

### 高空时代与知识制度

- **885**：稳定的长期高空活动成为现实。最初目的主要是资源、天气与大陆位置观测。
- **911**：人类首次穿出明亮蓝层，看到上方黑暗与星空，并从高空看见蓝色网络和钢铁大陆的宏观结构。三维世界测绘由此跃迁。
- **947**：蓝能第一次明确被用于社会处罚的强制执行，仪式裁决开始与技术执行结合。
- **1187**：学院建立。知识首次被大规模从家族、职业与聚落传统中抽离，形成长期集中保存与教学的制度。
- **1246**：第一联合建立。它不是领土帝国，而是共享仪式框架、公共航路、救援、仲裁与记录体系的跨共同体结构。
- **1331**：第三大陆架发生持续十九日的异常冰粒降水，长期影响当地入口与防滑设计。
- **1376**：蓝发男孩洛诺里俄斯出生。其后续人生尚未完全写定。

### 深海、制度崩解与战略时代

- **1437**：深海第一次在众人面前显露恐怖的一面。大陆下方黑暗中出现巨大表面运动与无法完整辨认的庞大结构，并推动数块中型钢铁区域。残损史料写道：“深海第一次在众人面前展开它恐怖的一面。世界上所有人都会记住祂的威名！■■统领…………”后文不可辨认。
- **1492**：第一联合崩解。没有战争；核心跨共同体仪式失去足够广泛的共同承认，共享合法性迅速瓦解。
- **1538**：赫西安·维洛系统化“非争斗对抗”的思想：不直接强迫对手，而是改变对手作出选择时面对的条件。后世对他评价极端分裂，常见评价是“狡诈无耻”。他打开了没有战争的文明仍可进行战略斗争的潘多拉之盒。
- **1577**：第一联合消亡85年后，旧联合休息设施仍被旅行者持续使用，成为“制度会死，习惯不会立即消失”的典型案例。
- **1673**：空洞核心遭不可逆破坏。其周边异常稳定的蓝能条件消失，部分路线与聚落随之衰退。破坏原因不明。
- **1725**：学院开始试点“惩罚值”处理不同势力间的责任分配。
- **1739前后**：惩罚值迅速从计算工具仪式化，人们开始说“举行一次惩罚值”。
- **1751**：出现故意制造低惩罚值争端以钻制度空子的早期记录。
- **1764**：一名烈焰新兵在高热蓝能作业中走失。搜索十一日无果。
- **1798**：远处封闭钢铁夹层发现疑似该作业团体使用过的标记，是否与1764失踪者有关无法证明。
- **1842**：首次出现提前制度化确认未来继任者的“储君”概念。

### 现代社会与世界结构问题

- **2008–2013左右**：“长充疫”爆发。患者需要异常漫长时间才能完成休息的充盈过程。公共休息场所成为关键传播环境，并迫使社会承认：被迫迁移休息地点不应自动改变归属。
- **2010**：一座废弃高空平台因金属疲劳坠入下方黑暗，无人员伤亡，成为重要工程维护案例。
- **2102**：第二大陆架中央蓝光剧烈增强约三日，并产生罕见的强方向阴影。事后许多长期变化趋势异常收敛，但当时无人理解其意义。
- **2110**：一块中型钢铁区域长时间从第三大陆架下方近距离经过，形成少量跨区域家庭。
- **2210**：占星学者已随处可见。911年后星空成为比漂移大陆更稳定的坐标参照，占星传统逐渐分化为精密测算、周期研究、历书与命运解释等多支。
- **2214**：学院地图编纂者讽刺九种流行星历给出九种相反命运解释，相关文字成为名句。
- **2267**：希拉克里波恩主张将蓝网、蓝层、光流与资源活动区视为同一底层存在的不同状态。这不是第一次给蓝色现象命名，而是一次统一自然概念的尝试。
- **2316**：生产记录抱怨“深渊触手仍然会干扰正常生产”。深层生物会被持续振动、热源及蓝能设备吸引，卷住机构或堵塞通道。
- **2339**：一次反复触手干扰最终追溯到新排水工程改变了下层水流，由此留下“施工前先看下面住着什么”的工程俗语。
- **2384**：归属保留运动成功，自动“归属迁移”制度被推翻。长期外居不再自动改变所属，主动转换才具有完整效力。
- **2391**：学院处理旧归属时发现，一座已经消失173年的聚落仍有四百余名法律意义上的成员。

### 维克索斯与“命运”

- **2491**：维克索斯出生于第二大陆架。他不是统领、贵族或预言者，成年后只是下层结构观测站的维护人员。
- **2507**：维克索斯在历史测量资料中发现“不可能重复”的结构位移与蓝网变化序列。
- **2509–2513**：他逐渐确认这些现象不像时间倒流，更像某种仍在工作的古代系统把偏离状态推回旧的稳定解。
- **2514**：维克索斯将资料提交学院。学界暂称其为“序列回归现象”。
- **2518**：调查队进入第二大陆架中央遗迹，并唤醒一处古代“连续性校正”节点。节点把现代人类社会的一部分视作需要修正的偏差，并开始重新排列巨构与蓝网。调查队无法摧毁节点，只能为其提供新的“当前参照”。这个参照必须持续观察并确认变化，因此必须由一个活着的意识承担。维克索斯选择留下，使系统不再把世界持续推回它记忆中的过去。

维克索斯最后留下的记录之一是：

> “别让它再把我们变回它记得的样子。”

此后他被称为 **“命运的守门人·维克索斯”**。他守护的不是卡牌规则，也未必是一扇物理门，而是“现在”不被古代系统重新覆盖的边界。世界之所以没有发生末日级变化，恰恰是这场牺牲成功的表现。

### 后维克索斯时代

- **2572**：有人提出将火舌小鬼纳入整备力量。它们好斗、耐热、能进入狭窄高温结构，并对温度、气流与蓝能异常敏感。
- **2579**：三处大型聚落正式保留并训练火舌小鬼用于基础设施整备。
- **2586**：第一家整备站因退休火舌小鬼的领养申请过多而制定专门流程。
- **2595**：发生第一次具有世界级象征意义的统领加冕。
- **2602**：出现未经完整加冕却已经实际履行统领职责的人，引发“统领权力究竟从何时开始”的争论。

## 6. 作者层隐藏真相（SPOILER / DEV CANON）

> 这一节是开发与长期叙事用真相，不要求在游戏开场直接告诉玩家。

### 世界本质：戴森球遗迹

已知世界并非天然钢铁行星。它位于一座已经毁坏、失去原始整体用途的**戴森球级巨构遗迹**内部。所谓钢铁大陆是内部壳层、承重结构、工业设施、生态区及其他巨构在漫长损坏后留下的碎片与区域。

蓝色网络与戴森球残存的能源传输、环境维持系统有关；持续明亮的“天空”是巨构内部照明/能量再分配系统残余。大陆的缓慢回摆可能与仍在运行的巨构姿态校正有关。统一的重力来自尚未完全失效的球级人工重力系统。

人类目前没有“戴森球”这一正确总体概念。

### 上古极神 Alpha

**上古极神 Alpha 是戴森球建造文明遗留下来的造物/系统实体，人类从未制造过它。**

克莱恩书院后世所谓“上古咒文·赋值机身”，本质上更接近人类误读并保存下来的古代控制序列与载体赋权过程。人类可以唤醒、调用或让某个载体承接 Alpha 的一部分身份，却不能因此声称自己创造了 Alpha。

Alpha 究竟是一台机器、一个分布式系统、一种权限、一个人格化进程，还是更大系统的局部实例，目前不要过早解释。

### 命运校正系统

维克索斯接触的系统与 Alpha 并非同一造物。它是巨构用于维护长期“状态连续性”的校正系统之一。它会记录、比较、预测并修正巨构状态；失去上层控制后，它长期以过时数据作为稳定目标，这才让人类观察到类似“命运干涉”的现象。

2518年之后，维克索斯成为新的动态参照。其意识是否仍完整、是否可与外界交流、系统是否已经改变他，均保持未解。

## 7. 卡牌叙事使用规范

1. **卡牌表现历史，不创造历史。** 先写人物与事件，再把它们卡牌化。
2. 卡牌数值与机制不是世界内物理定律。比如“弃18张牌取胜”不能解释为涛冥历史上真的让敌人丢18张东西。
3. 卡名可以是后世称号、俗称、戏剧化标题，不要求等于人物生前正式姓名。
4. 统领卡应保持最高叙事等级；不要把“统领”写成地方官或普通职业。
5. 中立卡优先承载跨时代历史人物、制度发明者、旅行者、思想家与无法被后世势力垄断的人物。
6. 世界真相应分层揭示。戴森球、Alpha、维克索斯的完整真相可以先只通过风味文本、遗迹档案与互相矛盾的史料露出边缘。

## 8. 当前仍保持未知的问题

- 谁建造了戴森球，以及建造文明为何消失。
- 蓝色网络的完整物理性质。
- 戴森球巨构真正的整体结构与规模。
- 大陆下方“深海”究竟是什么，1437年出现的巨物是什么。
- 第二大陆中央系统之外还存在多少仍在运行的节点。
- Alpha 的完整身份、目的与活动范围。
- 1673年空洞核心为何毁坏。
- 维克索斯2518年以后是否仍能被称作“人”。
- 依兰维索最终何时、以何种方式与人类历史正面相遇。
