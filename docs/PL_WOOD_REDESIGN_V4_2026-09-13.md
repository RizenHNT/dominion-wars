## 0. 实测诊断：要修的到底是什么

12 局木对局（对手 烈焰/机械/深海各 4）的封印生命轨迹：

```
0 → 0 → 0 → 0 → 0 → 52 → 116 → 114 → 356 → 352 → 496 → 489 → 649   ✅
0 → 10 → 10 → 16 → 24 → 36 → 34 → 452 → 448 → 607                  ✅
22 → 15 → 15 → 10 → 10 → 30 → 54 → 82 → 80 → 224 → 222 → 590        ✅
```

| 指标 | 值 |
|---|---|
| 古木胜率 | 3/12 = 25% |
| 打到 512 | 3/12 = 25% |
| 封印随从最高生命 | 均值 320 / **中位 456** / 最小 0 / 最大 649 |
| 扎根层数 | 均值 19.3 / 中位 20 / 最大 38 |
| 疯长层数 | 均值 2.17 / **中位 3（上限）** |
| 获胜回合 | 12–15 |

**三个结构性结论**：
1. **中位 456 ≈ 阈值 512** —— 它**差一点**，不是差很多。所以"再堆数值"边际很低。
2. **前 5 个回合轴上是 0** —— 玩家看不到任何反馈。**这是要修的主要问题。**
3. **中段是阶梯跳变**（36 → 452）—— 强化卡一次性放大数百点，**中间没有"小步走"**。
4. **最小 0** —— 有局根本没铺起来；铺垫没有韧性。

⇒ **owner 的判断正确：要修的是"反馈与节奏"，不是数值。**

## 1. 设计信条（v4）

1. **围着本作特有字段设计**：扎根 / 疯长 / 封印 / 云端栈 / 惩罚值 / 吟唱。
   **不要**再用"X 费 X/X 带某个通用词条"的模板。
2. **每张卡都要让玩家的操作变成可见反馈** —— 卡面上写出"你现在达到哪一档、下一档要多少"。
3. **用复合效果**：一张卡同时做两件互相咬合的事（如"封印自己换抽牌"）。
4. **允许超模**：RULES §13.5 明确每阵营 1–2 张超模卡。古木用它换"后期爆发"。
5. **攻击欲望低 ≠ 不能打**：用**秒杀**这类"不看攻击力"的机制，让少随从的古木仍有威胁。

## 2. 需要新增的字段（这就是 owner 说的"多设计一些字段"）

### 2.1 关键词（目前 15 个合法关键词里**只有 4 个有引擎行为**）

| 关键词 | 现状 | v4 是否实现 | 语义（RULES §13.1） |
|---|---|---|---|
| 嘲讽 / 圣盾 / 突袭 / 扰魔 | ✅ 已实现 | 用 | — |
| **秒杀（剧毒）** | ❌ 白名单里有、无行为 | **实现** | 造成伤害即消灭目标，无视伤害量；圣盾先抵消则不触发；**只在攻击路径判定**（否则 AOE 也秒杀） |
| **寄生** | ❌ 无行为 | **实现** | 每回合结束时抽走目标对面板（攻或血 N 点）强化自身；受目标离场/被反制打断；单卡寄生总量有上限 |
| **震慑** | ❌ 无行为 | **实现** | 目标下回合不能攻击 |
| **沉默** | ❌ 无行为 | **实现** | 目标失去全部关键词/触发效果（保留身材） |
| **占星** | ❌ 无行为 | **实现** | 查看己方牌库顶 N 张（可决定顺序/放回/弃置） |

**为什么先选这 5 个**：它们各自**服务古木的一条设计线** ——
秒杀 = 低攻击欲望下的威胁；寄生 = "养怪"的另一面（从敌人身上长）；
震慑 = 无伤回合（`NO_DAMAGE_TURNS_GE` 是古木的另一个已登记胜利条件）；
沉默 = 解场（owner 要的"解场多"）；占星 = 解决"抽不到强化卡"的空档。

### 2.2 新增状态字段

| 字段 | 语义 | 服务哪张卡 |
|---|---|---|
| `engrave`（刻痕） | 目标随从上累积的刻痕层数；每层给它 -1/-0；目标离场则清空 | 新卡「刻痕」「年轮剥离」 |
| `linkRoot`（连根） | 该随从受到扎根增幅时，**额外再吃一次**（即成长公式多算一轮） | 新卡「连根」 |
| `sacrificeSeal`（封魂） | 把己方一个随从封印，换取一次性收益 | 新卡「封魂」 |

> **登记流程**（RULES §13.4）：新机制定稿 → RULES §13 表登记 → `cards.schema.json` 枚举追加 →
> C# IEffect 实现 → `effects.contract.md` §2 同步。**v4 的新字段必须走完这条链才算实现。**

## 4. 玩法：玩家看得到的进度条

```
扎根 0 → 1 → 2 → 3 → 4 → 5 → 6 →              → 8
       苔藓+2血  德鲁伊双强化  橡木扰魔  迅藤秒杀  灰熊双强化  古树全体+2/+2    世界树灵全体圣盾
       └─ 年轮解锁抽2
```

**每张卡卡面写"下一档：扎根N"** ⇒ 玩家第 1 回合就知道目标，**前期空档从"无事可做"变成"在爬阶梯"**。

**四条互相咬合的线**（多样性来源）：
1. **阶梯线**：扎根 → 逐档解锁（上面那张表）
2. **刻痕线**：刻痕 → 年轮剥离（把小伤害变成处决）
3. **寄生线**：寄生藤从敌人身上长（同时消耗对手）
4. **封印线**：封魂把"封印"主动当资源换抽牌；盛放/盖亚之赐收割

## 5. 实现顺序（先做能测的，再叠复杂度）

| 批次 | 内容 | 可验收 |
|---|---|---|
| **B1** | 秒杀（攻击路径判定） | 古木低攻击随从能秒掉大怪 |
| **B2** | 扎根阶梯（`punishCondition` + 多效果） | 卡面门槛真的拦效果 |
| **B3** | 寄生 | 每回合抽面板，有上限，可打断 |
| **B4** | 沉默 / 震慑 / 占星 | 解场与摸牌质量 |
| **B5** | 新状态字段（刻痕 / 连根 / 封魂） | 走完 RULES §13.4 登记链 |

**每批都要跑 `WoodDesignProbe` 验收三件事**：
1. 封印生命**从第 1–2 回合就非零**（补掉前期空档）
2. **中位封印生命 ≥ 512**（不只是最大值漂亮）
3. **20 张卡全部被用到**（多样性不退）
