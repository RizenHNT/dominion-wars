# 当前实现状态地图

> 更新时间：2026-08-12。本文描述仓库当前事实，不把设计提案当成已实现功能。

## 一句话结论

当前项目是“Java 可运行旧原型 + C# 新引擎地基 + Unity/正式试玩界面尚未接通”，不是一套已经完成的 Unity 游戏。

## 已经能运行的部分

### Java 原型

- 从 JSON 读取卡牌、牌组和全局平衡参数。
- 进行完整的基础对局：抽牌、出牌、伏击、惩罚抽牌、惩罚连锁、战斗、弃牌和回合结束。
- 支持统领自动登场、统领耐久/生命、王城、特殊胜利条件和部分统领光环。
- 有规则回归测试、AI 对 AI 模拟、Swing 界面和本地 Web 界面。
- 当前证据：构建通过；规则回归 35/35；批量模拟 1200 局完成。

### 数据和契约

- 5 个卡牌 JSON 文件，共 91 张卡，91 个唯一 ID。
- 4 个预构筑卡组，每套当前 60–80 张范围内。
- 卡牌 schema 已覆盖当前真实字段；5 张 token 卡的空 `text` 字段已补齐。
- 效果动作、目标别名和统领持久光环已有独立契约表示。

## 已经搭好但还不能当完整游戏的部分

### C# Engine

- 有游戏状态、玩家状态、卡牌定义和卡牌实例。
- 有效果分发、目标选择、事件日志、随机数和命令缓冲接口。
- 有投影适配器，可把引擎状态转换为 UI/运行时快照。
- 设计目标是以后接 Unity；目前不是完整可玩的 C# 回合控制器。

### 运行时视觉契约

- 已有卡牌框、卡背、按钮、阶段图标、印章和纹理等设计资产。
- 已有 Snapshot、Action、Event 等接口方向。
- 这些资产和契约不是已完成的 Unity 牌桌，也不代表正式 UI 已经实现。

## 尚未完成

- C# 还没有完整复制并验证 Java 的整局回合流程。
- C# 还没有完成全部统领特殊胜利、伏击、惩罚链和牌组验证迁移。
- Unity 场景、牌桌、手牌交互、目标选择、胜利进度和合法性提示尚未接通。
- 还没有可交给朋友运行的正式 Unity Windows 试玩包。
- C# 测试需 .NET SDK；当前机器只有 Runtime，不能宣称 C# 测试通过。
- Python sanity/alignment 检查需 Python；当前终端没有 Python，本地本轮无法复跑。
- 星位、封锁体系、字段拆分和新检索机制都只是设计记录，尚未进入生产代码。

## 当前规则的权威边界

- Java 当前可执行行为是旧原型基线。
- Java 的 UI 和部分早期设计不是最终视觉或产品方向。
- 人类负责人已经确认的规则意图优先于旧原型细节；冲突需要先写成计划，再改 Java/C#。
- 本轮没有改变统领胜利方式、牌组平衡或现有对局规则。
