## 翻译备注

- “统领”暂译为「統領 / Leader」。如果后续世界观更偏王权，也可改为「君主 / Sovereign」。
- “王城”日语保留「王城」，英语用 “Royal Castle”。如果强调公共目标，也可用 “The Castle”。
- “惩罚”日语暂译为「ペナルティ」，英语用 “Punish”。后续如果想更卡牌化，可考虑 “Backlash / Reprisal”。
- “弑君”日语用「王殺し」，英语用 “King Slayer”。如果统领不一定是王，后续可改成 “Leader Slayer”。
